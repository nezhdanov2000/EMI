HOW IT WORKS (ALGORITHM)
═══════════════════════════════════════════════════════════════════════════════

Input:  X (features), Z (target), positive_class=1
        ↓
        Step 1: Discretize X and Z (identical to discover_branches)
        ↓
        Step 2: Create binary indicator z_binary = 1[Z = positive_class]
        ↓
        Step 3: INVERT (THE KEY INSIGHT)
                z_complement = 1 - z_binary
        ↓
        Step 4: Exhaustive search over all C(M, d) feature subsets
                using z_complement as the target
        ↓
        Step 5: Rank by coverage_score (same scoring as standard)
        ↓
        Step 6: Report results with all statistics computed on complement
        ↓
Output: Dict[int, BranchResult] where:
        - coverage: fraction of NON-positive_class rows found
        - purity: fraction of cells with low positive_class concentration
        - All other metrics: computed on complement (z_complement)

USAGE EXAMPLE
═══════════════════════════════════════════════════════════════════════════════

from vsf import discover_complement_branches, CenterSpec
import numpy as np

# Problem: Target is 90% positive (hard to find where it's present)
Z = np.random.binomial(1, 0.9, 1000)  # 90% disease prevalence
X = np.random.randn(1000, 15)

# Solution: Search for where disease is ABSENT (easier signal)
branches = discover_complement_branches(
    X, Z,
    positive_class=1,
    center_spec=CenterSpec(tau=0.90, alpha=0.05),
    n_permutations_centers=999,
)

# Results in branches[1], branches[2], etc.:
# - coverage: % of NON-diseased (Z=0) population found in cells
# - purity: % of each cell that is NON-diseased
# - certificates: statistical guarantees (Clopper-Pearson, p-values, CV)

for d, result in branches.items():
    print(f"d={d}: coverage={result.centers.coverage:.1%}, "
          f"K={result.centers.n_centers} cells")
